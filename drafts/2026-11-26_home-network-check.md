집 안의 모든 기기(PC, 스마트폰, TV, 홈캠, 도어락 앱, 로봇청소기)는 결국 하나의 공유기를 통해 인터넷에 나갑니다. 공유기가 뚫리면 집 전체가 노출되는 셈입니다. 이 글에서는 지금까지 배운 Wireshark·nmap을 활용해 우리 집 네트워크를 스스로 점검하는 순서를 체크리스트로 정리합니다.

## 1. 점검 전 준비: 내 공유기 파악하기

- 관리 페이지 주소: 보통 게이트웨이 IP(`192.168.0.1`, `192.168.1.1`, `10.0.0.1` 등). `ipconfig`(Windows) 또는 `ip route`(Linux)에서 "기본 게이트웨이"를 확인합니다.
- 제조사·모델명: 공유기 바닥 스티커에 있습니다. 이 정보로 제조사 홈페이지의 펌웨어·보안 공지를 찾습니다.
- 통신사 임대 공유기라면 일부 설정은 통신사가 관리하므로 고객센터 안내를 함께 확인하세요.

## 2. 관리자 계정과 원격 관리

| 점검 항목 | 권장 상태 |
|---|---|
| 관리자 비밀번호 | 초기값(admin/스티커 값) 사용 금지, 길고 고유한 값으로 변경 |
| 원격(외부) 관리 | 사용 안 하면 **끄기** |
| 관리 페이지 접속 | 가능하면 HTTPS, 유선/내부망에서만 |

> 공유기 관리자 비밀번호는 Wi-Fi 비밀번호와 **달라야** 합니다. 손님에게 Wi-Fi 비밀번호를 알려 줘도 공유기 설정까지 바꿀 수 없게 하기 위해서입니다.

## 3. Wi-Fi 암호화 설정

| 방식 | 판단 |
|---|---|
| WPA3-Personal | 지원 기기가 모두 되면 권장 |
| WPA2/WPA3 혼합 | 구형 기기가 있을 때 현실적인 선택 |
| WPA2-PSK(AES) | 최소 기준 |
| WEP, WPA(TKIP), 개방형 | **사용 금지** |

- Wi-Fi 비밀번호는 충분히 길게(문장형 추천) 설정합니다.
- **WPS(버튼/PIN 연결)**는 쓰지 않으면 끕니다. PIN 방식은 과거 공격 사례가 알려져 있습니다.

## 4. 펌웨어 업데이트

공유기도 컴퓨터라 보안 패치가 필요합니다. 관리 페이지의 "펌웨어 업그레이드" 메뉴나 자동 업데이트 설정을 확인하세요. 제조사가 더 이상 업데이트를 제공하지 않는(지원 종료) 모델이라면 교체를 검토하는 것이 좋습니다. 지원 여부는 제조사 공지에서 확인하세요.

## 5. 포트포워딩·DMZ·UPnP 점검

| 기능 | 위험 | 권장 |
|---|---|---|
| 포트포워딩 | 내부 기기 포트가 인터넷에 직접 노출 | 모르는 규칙은 삭제 |
| DMZ | 한 기기의 모든 포트를 외부에 노출 | 사용 안 하면 끄기 |
| UPnP | 기기·앱이 스스로 포트를 열 수 있음 | 필요 없으면 끄기 |

예전에 게임·NAS·홈캠 때문에 설정해 두고 잊어버린 규칙이 가장 흔한 위험 요소입니다.

## 6. 연결된 기기 목록 확인

1. 공유기 관리 페이지의 "연결 장치/DHCP 할당 목록"을 봅니다.
2. nmap으로 교차 확인합니다: `nmap -sn 192.168.0.0/24`
3. 기기 이름과 MAC 주소를 하나씩 대조해 모르는 기기가 없는지 확인합니다.

모르는 기기가 있다면 Wi-Fi 비밀번호를 바꾸고(모든 기기 재연결 필요), 관리자 비밀번호도 함께 변경하세요. 최근 스마트폰은 Wi-Fi마다 무작위 MAC을 쓰기도 하니 "모르는 MAC = 침입"으로 바로 단정하지는 마세요.

## 7. IoT 기기 분리와 점검

- **게스트 네트워크 활용**: TV, 홈캠, 스마트 플러그 같은 IoT 기기를 게스트 Wi-Fi(또는 별도 SSID)에 연결하면, 그 기기가 뚫려도 PC·NAS가 있는 메인 네트워크로 넘어오기 어렵습니다. 공유기의 "게스트 간 격리/내부망 접근 차단" 옵션도 켜 주세요.
- **홈캠**: 초기 비밀번호 변경, 앱·펌웨어 업데이트, 쓰지 않는 원격 보기 기능 끄기.
- **열린 포트 확인**: `nmap -sV 기기IP`로 Telnet(23) 같은 오래된 서비스가 열려 있지 않은지 봅니다.

## 8. 10단계 체크리스트

| # | 항목 | 완료 |
|---|---|---|
| 1 | 공유기 관리자 비밀번호 변경 | ☐ |
| 2 | 원격(외부) 관리 끄기 | ☐ |
| 3 | WPA2(AES) 이상, 가능하면 WPA3 | ☐ |
| 4 | Wi-Fi 비밀번호 길게 변경 | ☐ |
| 5 | WPS 끄기 | ☐ |
| 6 | 펌웨어 최신 확인, 지원 종료 모델 교체 검토 | ☐ |
| 7 | 포트포워딩·DMZ·UPnP 정리 | ☐ |
| 8 | 연결 기기 목록 대조(관리 페이지 + nmap) | ☐ |
| 9 | IoT 기기는 게스트 네트워크로 분리 | ☐ |
| 10 | 분기마다 이 체크리스트 반복 | ☐ |

메뉴 이름과 위치는 제조사·펌웨어마다 다르니 공유기 설명서나 제조사 고객지원 페이지를 함께 확인하세요.
